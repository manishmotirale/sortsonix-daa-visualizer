## 📊 Algorithm Complexity Quick Reference

<img src="https://user-images.githubusercontent.com/74038190/212284136-03988914-d899-44b4-b1d9-4eeccf656e44.gif" width="400">

</div>

| Algorithm | Best | Average | Worst | Space | Stable |
|-----------|:----:|:-------:|:-----:|:-----:|:------:|
| **Bubble Sort** | `O(n)` | `O(n²)` | `O(n²)` | `O(1)` | ✅ |
| **Selection Sort** | `O(n²)` | `O(n²)` | `O(n²)` | `O(1)` | ❌ |
| **Insertion Sort** | `O(n)` | `O(n²)` | `O(n²)` | `O(1)` | ✅ |
| **Quick Sort** | `O(n log n)` | `O(n log n)` | `O(n²)` | `O(log n)` | ❌ |
| **Merge Sort** | `O(n log n)` | `O(n log n)` | `O(n log n)` | `O(n)` | ✅ |
| **Heap Sort** | `O(n log n)` | `O(n log n)` | `O(n log n)` | `O(1)` | ❌ |
| **Counting Sort** | `O(n + k)` | `O(n + k)` | `O(n + k)` | `O(k)` | ✅ |
| **Radix Sort** | `O(d·(n+k))` | `O(d·(n+k))` | `O(d·(n+k))` | `O(n+k)` | ✅ |

## 🎵 Sound Synthesis Details

<img src="https://user-images.githubusercontent.com/74038190/212749447-bfb7e725-6987-49d9-ae85-2015e3e7cc41.gif" width="400">

</div>

Each algorithm family has a **unique sound signature**:

| Family | Waveform | Character |
|--------|----------|-----------|
| 🟦 **Elementary** | Triangle | Smooth, melodic tones |
| 🟩 **Divide & Conquer** | Sawtooth | Rich, aggressive harmonics |
| 🟨 **Non-Comparison** | Square | Sharp, digital tones |
| 🟪 **Exotic** | FM Synthesis | Complex, modulated sounds |

> 🎼 Notes are mapped to a **pentatonic scale** for musical harmony

## 🧪 Technical Highlights

<img src="https://user-images.githubusercontent.com/74038190/212257465-7ce8d493-cac5-494e-982a-5a9deb852c4b.gif" width="100">

</div>

### ⚡ Deterministic Execution
✅ Algorithms execute **ahead-of-time** to generate complete traces  
✅ Guarantees 100% sorted results  
✅ Playback is pure state replay (no runtime sorting)

### 🚀 Performance Optimizations
- Dynamic batching at high speeds (up to 13 steps per frame)
- Intelligent render throttling
- Memoized computations with React hooks

### 🎓 Educational Value
- Real algorithm implementations (not simplified demos)
- Complete complexity analysis
- Multi-language code samples (JavaScript, Python, C++)
- Step-by-step procedure documentation
